# Changelog

## [1.3.0] - 2026-10-30

### Changed
- Improved the visual appearance of the Preferences window to provide better integration with the GTK3 desktop environment.
- Updated text previews in the main window to display a maximum of three lines by default, with an expand/collapse button to show or hide the full content.
- Improved the expanded text layout in both the main window and the system tray menu. The expand/collapse, pin, and delete buttons now remain positioned at the top of the text content when expanded, keeping the controls easily accessible.
- Updated the delete icon in the system tray menu to match the one used in the main window, ensuring a consistent visual experience.

### Added
- Added several tooltips to make interface controls and their functions easier to understand.
- Added a search icon and a "No results found" message when a search returns no matching items.
- Added a "Clipboard history is empty" message when there are no items in the history.

### Fixed
- Updated and synchronized translations across all supported languages.

### Supported languages
English, Spanish, Italian, Brazilian Portuguese, French, German, Russian, Japanese, and Hungarian.
